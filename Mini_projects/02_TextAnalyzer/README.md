# 📝 Text Analyzer

**Dart Mini-Project — Intermediate Level**

## 📌 Description

Develop a program capable of analyzing a text and generating a statistical report in the console.

The text can be **entered by the user** or **initialized directly in a variable**.

## 🎯 Features

### 📊 General Information
Display:
- The original text
- Number of characters
- Number of words
- Number of lines
- Number of spaces

### 🔤 Character Analysis
Calculate:
- Uppercase letters
- Lowercase letters
- Digits
- Special characters
- Vowels
- Consonants

### 🔎 Search
Allow the user to search for a word and display:
- Whether it exists
- Number of occurrences
- Position of its first occurrence

### 🔄 Transformations
Display:
- Text in uppercase
- Text in lowercase
- Reversed text
- Text without unnecessary spaces
- Text with each word starting with an uppercase letter

## 📑 Final Report

Present all information in a **clear and readable format in the console**.

## 🛠️ Technology

- **Dart**
- Console application
